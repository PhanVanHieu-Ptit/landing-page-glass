# AERIS X1

React + TypeScript + Vite development shell for a continuous cinematic product narrative. GSAP/ScrollTrigger owns one normalized scroll timeline. Three.js, React Three Fiber and Drei are installed for subsequent product integration; the current shell does not mount a Canvas or fetch media.

```sh
npm install
npm run dev
npm run build
npm test
```

See [integration contracts](docs/INTEGRATION.md), [shared types](src/lib/contracts.ts) and [timeline ranges](src/animations/timeline.ts).

The first task intentionally contains labeled placeholders only. Athlete film, goggles model, interactive viewer and commerce implementation are pending. Reduced motion presents a static outline. No checkout or production assets are simulated.
